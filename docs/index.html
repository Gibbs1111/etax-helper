Phiên bản hiện tại: v2.0.2

eTax Helper Internal

Tiện ích Tampermonkey nội bộ hỗ trợ đội ngũ kế toán trên dichvucong.gdt.gov.vn và thuedientu.gdt.gov.vn: Chọn nhanh MST mã hóa PIN, Chọn ngày 2 cấp, Mở rộng bảng, Đồng hồ giữ phiên, Unified Dock định danh công ty & Ghi chú, Trợ lý Mã Chương/Tiểu mục + chấm đối soát Xanh/Đỏ, Truy cập nhanh & Ghim tờ khai (Ctrl+K), và Kiểm tra trạng thái CT SigningHub & eSigner.

⚡ Cài đặt / Cập nhật eTax Helper (v2.0.2) 📄 Tải Excel mẫu 5 cột (.xlsx)

Hướng dẫn cài đặt nhanh trong 3 bước

  1. Cài tiện ích Tampermonkey trên Chrome/Edge (nhớ bật Allow User Scripts / Chế độ nhà phát triển trong Quản lý tiện ích của trình duyệt).
  2. Bấm nút màu xanh Cài đặt / Cập nhật eTax Helper ở trên → bấm Install trong màn hình Tampermonkey vừa mở.
  3. Mở https://dichvucong.gdt.gov.vn/tthc/login để tạo mã PIN cục bộ, nhập hoặc Import file Excel 5 cột và sử dụng. Bấm vào biểu tượng Tampermonkey để tự bật/tắt độc lập từng tính năng.
🔐 Cam kết bảo mật cục bộ: Toàn bộ Mã số thuế, Tài khoản và Mật khẩu chỉ lưu trên trình duyệt từng máy với mã hóa AES-256-GCM + mã PIN cá nhân, tuyệt đối không gửi ra bất kỳ máy chủ bên ngoài nào. Các bản cập nhật tự động sau này luôn bảo toàn 100% dữ liệu đã lưu của bạn.
